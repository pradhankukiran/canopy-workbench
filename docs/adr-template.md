# ADR Template

Use this template for Architecture Decision Records (ADRs).

Suggested path for new ADRs: `docs/adrs/NNNN-short-title.md`

---

# ADR-NNNN: Decision Title

- Status: Proposed | Accepted | Superseded | Deprecated
- Date: YYYY-MM-DD
- Owners: team/person
- Related: issue/PR/doc links

## Context

Describe the problem, constraints, and why a decision is needed now.

## Decision

State the chosen approach clearly and specifically.

## Alternatives Considered

List the main alternatives and why they were not selected.

## Consequences

Document the expected tradeoffs, risks, and follow-up work.

## Implementation Notes (Optional)

Add rollout sequencing, migration notes, and validation steps if relevant.
